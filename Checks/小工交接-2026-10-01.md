## 已交给主控的 workflows.json 稳定格式

主控负责写此文件与 previews，不要本子代理和新任务并发覆盖。当前代码按以下字段解码（可选字段用 `?` 说明，JSON 里不带问号）：

```json
{
  "schema": 1,
  "workflows": [{
    "id": "screen-demo",
    "title": "实操录屏",
    "summary": "适用处境",
    "engine": "recording",
    "script_structure": ["场景", "真实动作", "真实结果"],
    "frame_recommendation": "horizontal",
    "source_paths": ["绝对工作流路径"],
    "voice_hint": "可选，已批准音轨建议",
    "availability": "ready",
    "unavailable_reason": "可选，外部或实验路线说明",
    "preview_file": "绝对mp4路径，缺失为空字符串",
    "thumbnail_path": "绝对png路径，缺失为空字符串",
    "preview_status": "silent_candidate",
    "production_goals": ["batch", "polished"],
    "keywords": ["录屏", "工具", "操作"],
    "costs": {
      "editing": "固定剪辑，不调用视频模型",
      "writing": "Luna按需生成，实际金额未知",
      "voice": "现有本地音色或导入音轨，实际金额未知",
      "video_model": "不调用，外部流程另行确认",
      "time": "依素材与精修，未计时"
    }
  }]
}
```

- engine：recording／montage／screenshot／comparison／manual。
- availability：ready／manual／experiment。
- frame_recommendation：horizontal／vertical／platform。
- preview_status：silent_candidate／voiced_candidate／accepted／not_available；未经用户实际接受不能用 accepted。
- keywords、voice_hint、unavailable_reason 是可选字段；其余当前 Codable 要求存在。
- 故事接操作可映射 recording，短字幕快片可映射 montage，由 script_structure 区分；白板／中转英用 manual，卡通用 experiment＋manual engine。
