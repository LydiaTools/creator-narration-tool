## 此前功能说明（0.2.1）

- 写一句想法，调用 Codex Luna low 生成初稿、镜头安排和建议音色。稿子由每段口播拼成，避免两份稿件不一致。需要联网和现有 Codex 登录；不是完全离线。
- 录屏讲解：导入真实录屏，选择片段、取景与聚焦，生成横版或竖版画面。
- 素材混剪：按镜头顺序拼接已确认来源的视频或图片。保留源片与输出时间码，不循环素材填满，不以白板自动替代缺失镜头。
- 音色库推荐、导入现成配音、合成待审片。原有本地配音按需运行，内存保护触发时停止；当前轮没有重新运行大模型配音。
- 左侧“看示例”新增8.67秒带声短样；写文字页有11条流程画廊、真实预览与成本说明。旧白板样片保留在资料和备份中，已退出日常列表。

当前镜头匹配依据文件名和关键词，不是完整视觉理解。镜头聚焦位置由本期安排或取景选择决定，不是自动追踪鼠标。未填精确起点时，声画时长和字幕按段落估算，必须试听后校准。当前没有一键自动录屏或自动控制剪映；用户先导入已有录屏。

## 录屏与素材呈现

所有成片遵守[视频制作规范第10节：不带 Computer Use 虚拟箭头](/Users/macmini/Documents/ChatGPT/我的口播视频/00-视频制作必备-注意力四要素与成本检查.md#10-所有视频不带-computer-use-虚拟箭头2026-10-01)，包括导入的录屏素材。录屏模板默认 `showsCursor=false`，已有 `showMouseClicks` 参数一并设为 `false`。这两个开关隐藏原生鼠标与点击效果，不能证明独立的 Computer Use 操作浮层已被排除；正式录制前仍需检查干净短样，导出后检查实际编码画面。

含虚拟指针的导入素材不合格，优先用同一操作的干净源片替换；已有分层素材则关闭指针叠加层后重新导出。需要强调操作时使用短时局部高亮，保留流程图的语义箭头与产品原生图标。本工具没有接通自动去除已编码指针的功能。播放器外部浮层不作为重渲染依据，应先核对原视频文件。

## 构建

```sh
./build-native.sh
```

构建结果为 `build/口播制作.app`。本机复用既有 FFmpeg、Codex bundled Python/Pillow 与 Codex CLI；构建不下载大模型。当前有本机绝对依赖路径，尚不是跨机器安装包。音色生成沿用已授权的外盘档案；为兼容既有登录，Codex 工作目录仍使用内部的 `Library/Application Support/镜头工位/Codex`，不会复制登录凭证到外盘或仓库。
